# Heart Disease Prediction App

A machine learning-based web application to predict the risk of heart disease using k-Nearest Neighbors (kNN) algorithm.

## 🚀 Live Demo

**[Open Streamlit App](https://heart-disease-prediction-atbjfw7dnxcqwkjqjmia8p.streamlit.app/)**

## 📋 Features

- Age, sex, and medical history input
- Real-time heart disease risk prediction
- User-friendly interface with sliders and dropdowns

## 📊 Dataset

Uses the Heart Disease dataset with features like:
- Age, Sex, Chest Pain Type
- Blood Pressure, Cholesterol
- Max Heart Rate, Oldpeak, ST Slope

## 🛠️ Technologies Used

- Python
- Streamlit
- scikit-learn
- Pandas
- Joblib
